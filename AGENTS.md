# AGENTS.md — AI Cards

## Что это

Приложение карточек для изучения языков: backend на Python, frontend на React/Vite, PostgreSQL и Docker Compose. Подробности — в `README.md`.

## Правила работы

- Сначала прочитай `README.md` и этот файл.
- Держи `README.md` актуальным: статус, следующий шаг, ключевые файлы.
- Итог сессии — в `dialogs/YYYY-MM-DD-тема.md` (задача, что сделано, где файлы, следующий шаг).
- Не выдумывай факты и не оставляй секреты в репозитории.
- Не создавай пустую бюрократию: документ появляется, когда есть содержание.

## Команды

Точные команды — в `README.md`. Если их там нет, добавь при первом запуске. Если меняешь команды, обнови README и этот файл.

## Границы и проверка

- Не трогай сгенерированные файлы и секреты.
- Перед изменением поведения посмотри существующие тесты.
- В конце запусти тесты/линт и запиши результат в итог сессии.
- Для нетривиальной фичи сначала короткий спек в `docs/specs/`, потом код.
- Значимые решения — в `docs/decisions.md`.

## Где что лежит

- `docs/` — архитектура, решения, спеки.
- `dialogs/` — итоги сессий.
