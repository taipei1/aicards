# AI Cards

**Статус:** active  
**Профиль:** code

## Что это

Приложение карточек для изучения языков: backend на Python, frontend на React/Vite, PostgreSQL и Docker Compose.

В Learning есть режим **Phrases**: вместо голого слова карточка показывает
короткую AI-фразу и её русский перевод с подсветкой изучаемого слова.

## Phrase mode (Learning)

- Кнопка `Phrases ON/OFF` рядом с выбором языка; выбор хранится в `localStorage`.
- Фразы генерируются в фоне и кэшируются в таблице `card_phrases`.
- Силу модели выбирают замером, а не на глаз: реальный промпт приложения,
  батч 20, детерминированная валидация + косинусная близость перевода к
  смыслу карточки + слепой LLM-судья с якорями. Победил
  `tokenharbor/deepseek-v4.1-flash:free`: 0.91 валидных ответов, sim 0.70,
  судья 4.95/5, ~8 с на батч 20.
- Комбо `aicards-phrase` в локальном OmniRoute (strategy `priority`):
  `tokenharbor/deepseek-v4.1-flash:free`, `tokenharbor/mimo-v2.6-flash:free`,
  `nvidia/minimaxai/minimax-m3.1-flash`,
  `bluesminds/deepseek-v4.1-flash-uncen`.
- В батч идёт до 20 карточек: одна сильная модель отвечает на 20 так же
  валидно, как на 10, поэтому лучше один большой запрос, чем два маленьких.
  Первые 5 карточек видимой очереди по-прежнему уходят отдельным маленьким
  батчем, чтобы не ждать полный ответ.
- Для фраз разрешён отдельный провайдер: `PHRASE_BASE_URL`, `PHRASE_API_KEY`,
  `PHRASE_MODEL` (модели через запятую — первая ответившая выигрывает).
  Это нужно серверу, где OmniRoute недоступен: он ходит прямо в
  OpenAI-совместимый endpoint сильной модели.
- Groq-fallback для фраз отключён: слабая модель, написавшая мусор, хуже
  голого слова на пару секунд. Остальные фичи (Sentence/More) fallback
  сохраняют.
- Модель и base URL хранятся в БД (`omnirouter.chat_model`,
  `omnirouter.base_url`) и переопределяют `.env`; `PHRASE_*` — отдельный
  слой поверх активного профиля.
- Одна фраза на карточку, общая для прямого и обратного направления.
- Карточка, которая уже является фразой/предложением, не повторяется дословно:
  модель заменяет обобщённое слово конкретным (`Nefunguje mi to.` →
  `Nefunguje mi počítač.`), а грамматически чувствительные конструкции
  (`To je presne ono.`, `Podarilo sa mi to.`) оставляет целиком и добавляет
  контекст.
- Если переигровка не прошла валидацию, retry возвращает исходную фразу
  целиком; карточка не остаётся без фразы.
- Пока фразы нет, показывается слово. Готовая фраза подменяет текст без
  перезагрузки, без сброса таймера и без изменения очереди.
- Под карточкой с фразой подписано, какая модель её сгенерировала
  (`model (phrase): ...`, включая сработавший fallback).
- Emergency не затронут: там нет ни кнопки, ни фраз.
- Прогресс `Item N of M`, порядок карточек и FSRS не меняются.
- Спека: `docs/specs/phrase-mode.md`. Решения: `docs/decisions.md`.

## Отзывчивость оценок

- Кнопки `1–4` сразу переводят на следующую карточку; запрос `/reviews`
  сохраняется в фоне. Раньше интерфейс ждал ответа сервера, и награда
  выглядела как микро-фриз.
- Ошибка сохранения показывается плашкой, а не оставляет карточку «зависшей».

## Устойчивость к зависаниям

- Проверка токена вынесена из event loop в threadpool и кэшируется на 30 с
  (logout сбрасывает кэш сразу).
- Пул подключений к удалённой PostgreSQL: `pool_pre_ping`, `pool_recycle`,
  таймауты соединения/запроса — «протухшее» соединение больше не вешает API.
- Очередь и поиск считают отзывы одним grouped-запросом вместо N+1; теги
  читаются без гидратации всех карточек.
- Frontend: таймауты запросов, защита от гонок при смене языка, ошибка с
  `Retry` вместо вечного `Loading...`.

## Единый дизайн

Правила и план перехода на семантические токены и общие компоненты —
`docs/design-consistency.md`. Коротко: цвет только через `var(--token)`,
интерактив — через `components/ui`, сырые hex запрещены линтом
(`npm run lint:design`, появляется вместе с внедрением).

## Статистика

Страница собрана из блоков:

- «Сегодня» — итог дня, «Место дня» (в какой топ-процент активных дней года
  попадает сегодняшний по числу повторений) и разбивка по языкам.
- «Неделя» — та же неделя против прошлой по тот же день недели.
- «Активность» — ритм, серии и календарь года.
- «Слова» — «Приток слов и учёба»: добавленные слова против впервые
  повторённых, неделя к неделе, запас неначатых слов и вердикт
  «успеваю / не успеваю».
- «Зрелость колод» — внизу страницы: отдельные панели для en и sk, текущий
  срез по колодам и stacked-area динамика долей (не повторялось / 1 раз /
  2–3 раза / 4+ раза) от размера колоды на каждую дату.
  Спека: `docs/specs/deck-flow-stats.md`.

## Запуск

```bash
docker compose up -d
```

## Деплой

`./deploy.sh` собирает образы локально, копирует их на `translatepls.me`
(74.161.40.29) и перезапускает контейнеры. Скрипт требует чистого дерева и
запушенного `main`. Если копирование рвётся, образы докачиваются через
`rsync --append --partial` из `/tmp/aicards-*.tar.gz`.

Локальный `.env` указывает на localhost-БД, а боевой контейнер ходит в Azure
PostgreSQL, поэтому пересборку локального боевого контейнера делай с env из
`docker inspect srs_backend` (см. `dialogs/2026-11-14-phrase-model-combo.md`).

На сервере нет OmniRoute (`localhost:20128` недоступен), поэтому фразы там
генерирует отдельный провайдер из `PHRASE_BASE_URL`/`PHRASE_API_KEY`/
`PHRASE_MODEL` — сейчас это `tokenharbor.ai` с
`deepseek-v4.1-flash:free,mimo-v2.6-flash:free`. Остальные LLM-фичи идут
через активный профиль OmniRoute, как и раньше.

- `backend/` — API, модели, миграции Alembic, тесты.

- `docker-compose.yml`, `init.sql` — инфраструктура и база.
- `docs/` — спеки и решения.
