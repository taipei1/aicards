# 2026-11-15 — Деплой режима фраз на translatepls.me

## Задача

Закоммитить накопленную работу по режиму фраз и раскатать её на сервер.

## Что сделано

- Коммит `6b06190` (`feat(phrases): cached phrase mode with model attribution`):
  backend, миграция `card_phrases`, `/api/phrases`, фронтенд, тесты, docs,
  dialogs, README, AGENTS, конфиг комбо `aicards-phrase`.
- `git push origin main` — успешно.
- `./deploy.sh`: образы собраны (frontend 21 MB, backend 445 MB gz), но `scp`
  дважды оборвался («Network is unreachable», затем `rsync io timeout`).
  Докачал через `rsync --append --partial` с 364-го мегабайта, проверил
  `gzip -t`, загрузил образы (`docker load`) и пересоздал контейнеры на сервере.
- Убрал образы с сервера и из локального `/tmp` после деплоя.

## Проверка

- `https://translatepls.me/` → 200; бандл `assets/index-CVr0C7eD.js` совпадает
  с локальной сборкой и содержит "Phrases".
- `POST https://translatepls.me/api/phrases/status` → 200; для карточек 5860 и
  5866 отдаёт закэшированные фразы `gemini-3.6-flash` из общей Azure-БД.
- `docker ps`: `srs_backend` и `srs_frontend` пересозданы, alembic прошёл без
  изменений, в логах нет ошибок.

## Важно

- На сервере **нет OmniRoute**: `localhost:20128` и `91.184.253.167:20128`
  отдают 000. Значит, новые (ещё не закэшированные) фразы на сервере будет
  генерировать Groq `gpt-oss-120b`, а не `aicards-phrase`. Уже созданные
  Gemini-фразы в общей БД показываются как есть.
- Сервер маленький: 2 ядра, 842 MB RAM (свободно ~185 MB), поэтому собирать
  образы на нём не стоит — только `docker load` готовых.
- Чекаут в `/home/azureuser/aicards` — июньский, с локальными правками
  (groq/couchdb). Это те же изменения, что уже есть в git; деплой идёт
  образами, поэтому исходники на сервере не важны, но `git pull` там делать
  нельзя без ревью локальных правок.
